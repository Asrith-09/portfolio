Foundation design & placement

ETABS reactions become designed, checked, grouped footings — modelled back into ETABS.

Reads column reactions and the selected load combinations, sizes isolated footings against safe bearing capacity, runs punching and one-way shear checks, groups footings within a set tolerance, and writes the geometry back through the API.

Model QA · ETABS

Catching section drift before review does

A validator that checks every section against the name it was given.

Section names carry intent — dimensions, grade, sometimes a type prefix. The tool parses that intent, reads the actual geometry through the API, and compares. Names it cannot parse are reported separately rather than passed silently, because those are the ones worth a human look.

1,000+ sections in under 30 seconds · two mismatches caught that passed visual review

Drawing automation

Excel → AutoCAD beam schedules

Design output to drawing, without retyping.

Reinforcement output is read from Excel and drawn as dimensioned beam elevations in AutoCAD, with rebar callouts, hook geometry, beam marks, layers, and annotation applied automatically. Cover, bar gap, and hook offsets are parameters, so output matches an office standard rather than mine.

Output cross-checked against manually produced schedules for the same beams

In development

Where the toolkit is going.

These are being built, not finished. They move into the work above when they run against a real model.

  1. MCP layerA Model Context Protocol server over the toolkit, so a model can be queried and driven in plain language. ETABS and Grasshopper adapters first, Revit after.
  2. Model diffAn ETABS to Revit comparison for section sizes, materials, level elevations, and member presence. The two models share no element ID, so matching is by grid, level and mark, with proximity as a fallback and ambiguous matches flagged rather than guessed.
  3. Revit linkPlacement for the foundation tool — footing families placed, sized, tagged, and scheduled from the design output, closing the chain from analysis to BIM.
